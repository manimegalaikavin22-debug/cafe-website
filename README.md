# ☕ Brew & Bite Cafe

A modern and responsive cafe website created using HTML, CSS and JavaScript.

## Features

- Responsive design
- CSS Grid
- CSS Flexbox
- Mobile navigation
- Cafe menu section
- Special offer section
- Contact section
- Hover animations
- Scroll animations
- Interactive order button

## Technologies

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox

## Run Locally

Open `index.html` in a browser.

Or use VS Code Live Server.
